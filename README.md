# To-Do List Application (Python)

## Project Description
This is a simple command-line To-Do List application developed in Python as part of the Decode Labs Python Internship.

## Features
- Add Tasks
- View Tasks
- Delete Tasks
- Exit Program

## Technologies Used
- Python 3
- VS Code

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run:

```bash
python3 a.py
```
